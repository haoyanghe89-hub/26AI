# Terms of Use

Last updated: 2026-04-28

These terms are a baseline template for deployments of Twentys1x.

## Acceptable Use

Users must not use the product to upload, generate, or distribute unlawful, abusive, infringing, or malicious content. Users are responsible for ensuring they have the right to upload any files or project code they provide.

## AI Output

AI-generated output can be inaccurate or incomplete. Users should review generated content, code, and file changes before relying on them in production.

## API Keys

Users are responsible for the API keys they provide. For production deployments, operators should prefer server-side environment variables instead of collecting user keys in the frontend.

## File Operations

Project file preview and write features can modify files. Users should review diffs and maintain backups or version control before applying changes.

## Availability

The product depends on local infrastructure and third-party AI providers. Availability and response quality are not guaranteed.

## Operator Terms

Before public launch, replace this template with terms reviewed for the actual operator, jurisdiction, support policy, billing model, and data processing practices.
