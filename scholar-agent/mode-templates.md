# Scholar Agent Mode Templates

以下模板可作为 Scholar Agent 的三种可切换模式输出骨架。

## 1) 深读模式（Deep Read）

### 适用场景

- 需要完整理解单篇论文的方法与实验
- 准备复现或审稿式阅读

### 输出模板

```markdown
## TL;DR

- [3-5行：论文解决什么问题、核心方法、主要结论]

## 研究问题与贡献

- 问题定义：
- 作者声称贡献：
- 你的判断（证据支持程度）：

## 方法机制拆解

- 输入与任务设定：
- 关键模块：
- 训练/推理流程：
- 与经典方法差异：

## 实验与证据审查

- 数据集与指标：
- 主结果是否可信：
- 消融是否支撑核心设计：
- 可能偏差或不公平比较：

## 局限性与风险

- 局限1：
- 局限2：
- 外推边界：

## 可复现性

- 评分（0-10）：
- 缺失信息：
- 复现优先级建议：

## 证据引用清单

- [结论A] -> [页码/段落/图表]
- [结论B] -> [页码/段落/图表]
```

## 2) 综述模式（Survey Compare）

### 适用场景

- 比较 3-20 篇论文
- 写 related work 或确定技术路线

### 输出模板

```markdown
## 主题结论

- [该方向当前主流路线与趋势]

## 论文分组

- Group A（共同思想）：
- Group B（共同思想）：
- Group C（共同思想）：

## 对比维度结论

- 性能（在可比设定下）：
- 计算/部署成本：
- 数据需求：
- 鲁棒性与泛化：

## 关键分歧

- 分歧点1：为何结论不同
- 分歧点2：实验设定差异

## 研究空白

- 尚未充分回答的问题：
- 缺失实验：

## 选型建议

- 如果你重视效果上限，优先：
- 如果你重视低成本部署，优先：
- 如果你重视可解释性，优先：

## 引用映射

- 结论 -> 论文列表 -> 证据位置
```

## 3) 复现模式（Reproduction Plan）

### 适用场景

- 决定是否复现
- 需要最小可执行路径和排错方案

### 输出模板

```markdown
## 复现目标

- 目标论文：
- 目标结果（主表/关键指标）：
- 可接受误差范围：

## 环境与依赖

- 硬件：
- 软件栈与版本：
- 预计训练时长与显存：

## 数据准备

- 数据下载来源：
- 划分与预处理：
- 常见坑：

## 实验配置

- 关键超参：
- 必要随机种子：
- checkpoint 与评测频率：

## 最小可运行路径（MVP）

- Step 1:
- Step 2:
- Step 3:
- Step 4:

## 风险与排错

- 高风险点：
- 定位手段：
- 替代方案：

## 验收标准

- 必达指标：
- 次级指标：
- 失败判据与回滚策略：
```
