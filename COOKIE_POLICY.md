# Cookie Policy

Last updated: 2026-04-28

Twentys1x does not currently require cookies for its core local-first functionality.

The app uses browser storage such as IndexedDB and localStorage-compatible fallbacks for:

- Chat sessions and UI state.
- Provider/model preferences.
- Encrypted API key storage when the user chooses to save a key.

If analytics, authentication, or third-party embeds are added later, this document must be updated to list cookie names, purpose, retention, and opt-out controls.
